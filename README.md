## 托管与非托管 VPS 到底意味着什么

这两种方案运行在相同类型的硬件上：物理服务器的虚拟化切片，拥有专用的 CPU、内存和存储，介于共享主机和完整独立服务器之间。区别不在于机器本身——而在于随之而来的工作描述。

| 任务 | 托管 VPS | 非托管 VPS |
| --- | --- | --- |
| 操作系统安装和更新 | 提供商负责 | 您负责 |
| 安全补丁和防火墙 | 提供商负责 | 您负责 |
| 备份 | 自动化，通常包含在内 | 您设置并验证 |
| 监控和事件响应 | 24/7 全天候，包含在内 | 您自行监控（或添加自己的工具） |
| 崩溃的 Web 服务器或数据库 | 提供商的支持团队负责修复 | 您负责修复 |
| 硬件故障或网络中断 | 提供商负责修复 | 提供商负责修复 —— 这一行从不变动 |

最后那一行比看起来更重要。即使是非托管计划，其支持范围也有底线；下文将对此进行详细说明。

使用非托管方案，“完整 root 权限”正如其字面意思：您可以安装任何东西、破坏任何东西，并修复任何东西。RackNerd 在每个方案中都提供 root 权限，并将服务器管理视为您的职责。使用托管方案，提供商会接管该职责——但作为交换，您能保留多少控制权因主机商而异，这比大多数功能对比表所承认的更为重要。

## 大多数对比表格遗漏的三个细节

对比表格解决了基础知识问题；这三个细节决定了实际购买。

### “托管”并非标准化的产品

例如，Hostwinds 在其托管方案中包含完整 root 权限，而另一家主机商的托管 VPS 文档明确将 root 权限列为不包含。两家公司都没有误导——它们对该词的定义不同。在支付托管溢价之前，请询问：我拥有 root 权限吗？谁在应用内核补丁？备份是否包含在内，并且有人真正测试过恢复吗？具体排除了哪些内容——应用程序错误是否算在内？响应时间承诺是什么？续订时的价格是多少？这六个问题的书面答案比任何功能网格都更有用。

### 非托管支持涵盖的范围比人们预期的要广

非托管计划仍然提供支持，只是划分界限很明确：虚拟机之下的一切——物理硬件、网络连接、虚拟化平台、控制台访问——仍然是主机商的问题，而虚拟机内部的一切则是您的责任。如果宿主机在周日宕机，您提交工单，提供商会进行修复。如果您的 Nginx 配置导致网站宕机，使用的是相同的工单系统，但修复工作由您自己完成。您是第一响应者，对服务器内部发生的一切负责。

### 购买前检查虚拟化类型

非托管市场分为完全虚拟化（KVM）和基于容器的平台（OpenVZ/LXC）。KVM 为您提供自己的内核：您可以运行 Docker、加载自定义内核模块并部署任何发行版。容器共享宿主机的内核，成本更低，但当您在做有意思的项目时，它们施加的限制就会显现出来。RackNerd 的整个 VPS 产品线均基于 KVM——如果自定义技术栈是您选择非托管的初衷，这正是您所需要的。

## 那么您应该选择哪一种？

没有 IT 人员的企业选择托管；能够自己管理服务器的个人选择非托管；还有一小部分人应该完全跳过 VPS。具体来说：

**如果以下情况，选择托管 VPS：**
- 网站能产生收入，且停机成本高于管理费
- 您的团队中没有人愿意在半夜执行 `apt upgrade`（或者根本不知道这意味着什么）
- 您正从共享主机升级，并希望在获得更多性能的同时保持同样的省心
- 您希望备份、监控和安全工作由专业团队处理

**如果以下情况，选择非托管 VPS：**
- 您足够熟悉 Linux，可以在一小时内加固一台新服务器
- 您需要托管环境通常会限制的自定义技术栈 —— Docker、Node.js、非标准数据库
- 环境是用于开发、测试或学习，在这些场景下正常运行时间并不关键
- 预算是限制，而技术不是

如果静态网站或小博客是您所需要的，可以完全跳过 VPS —— 共享或静态主机更便宜，而且完全消除了管理问题。

## 常见问题

**非托管 VPS 是否提供任何技术支持？**
有，但仅限于基础设施层面：物理硬件、网络连接、虚拟化平台和控制台访问。您的操作系统、软件和应用程序仍由您自己负责。

**我以后可以从非托管切换到托管吗？**
在同时销售两者的主机商处，是可以的 —— 例如，Hostwinds 声明您可以根据需求变化调整您的方案类型。走向相反的方向（切换到像 RackNerd 这样的廉价非托管专家）是一种迁移，而不是简单的切换：您需要先自己备份数据，然后重新部署。

**我可以在托管 VPS 上安装自己的软件（如 Docker）吗？**
通常可以，但受支持的软件和自定义程度取决于提供商的政策。如果您需要非标准技术栈，请在付款前确认具体允许的内容。

**托管 VPS 物有所值吗？**
如果您没有系统管理员且网站不能承受停机，通常是值得的 —— 节省的管理时间通常能抵消价格差距。如果您熟悉命令行，通常就不值了，因为您需要为本来就会自己做的事情付费。

**如果我在非托管 VPS 上破坏了某些东西，会发生什么？**
您需要自己修复：撤销更改、从快照还原或重新安装操作系统。提供商仅在故障在于您虚拟机之外时才会介入。这就是为什么备份 —— 您自己制作的备份 —— 是您唯一真正的安全网。
